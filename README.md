# Landing page SAFTECH Infrastructures

Site statique (HTML, CSS, JavaScript), sans outil de build. Ouvre `index.html` dans un navigateur pour le voir.

## Contenu
- `index.html` : la page, avec le SEO de base (title, description, Open Graph, données structurées).
- `css/style.css` : styles et couleurs de la charte (variables en haut du fichier).
- `js/main.js` : menu mobile, formulaire de contact, motif de courbes de niveau du hero.
- `assets/img/` : photos, logos et logos partenaires extraits de la plaquette, en WebP.

## À compléter avant la mise en ligne
- Liens LinkedIn et Facebook dans le pied de page (`href="#"`, repérés par un commentaire « À COMPLÉTER »).
- Le formulaire ouvre un e-mail pré-rempli vers contact@saftech-infrastructures.com. Pour recevoir les demandes sans passer par la messagerie du visiteur, on peut le brancher sur un service comme Formspree.

## Mise en ligne
Copier tout le dossier (sauf PLAN.md et README.md) à la racine de l'hébergement : hébergeur mutualisé, Netlify ou GitHub Pages.
